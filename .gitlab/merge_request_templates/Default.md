## منع تكرار العمل (قاعدة ملزمة)

- [ ] شغّلت `pnpm run work:find "<المجال>"` قبل الكتابة، ولا يوجد عمل مطابق ولا حجز نشط لغيري
- [ ] سطر الحجز موجود في `docs/16-progress/WORK_CLAIMS.md` بحالة `Active` ويطابق فرعي
- [ ] كل ملف عدّلته يقع داخل النطاق المحجوز — لا توسيع نطاق بعد بدء الكتابة
- [ ] راجعت `docs/16-progress/WORK_INDEX.md`: المنطقة ليست `Placeholder بقرار` في ADR

> وظيفة `governance-guard` تتحقق من هذا آلياً وترفض التقاطع والخروج عن النطاق.

## نوع التغيير

- [ ] feat: ميزة جديدة
- [ ] fix: إصلاح عطل
- [ ] refactor: إعادة هيكلة
- [ ] docs: توثيق
- [ ] chore: إعداد/صيانة
- [ ] breaking: تغيير كسري

## التوثيق (قاعدة ملزمة)

- [ ] إدخال جديد في `docs/16-progress/TASK_LOG.md` يتضمن سطر `**Work Item(s):** Mx-yy`
- [ ] صف اللوحة في `docs/16-progress/LAUNCH_EXECUTION_BOARD.md` محدَّث (حالة/دليل/عائق/خطوة تالية)
- [ ] تم تعديل/إضافة ADR إن كان القرار معمارياً
- [ ] روابط الوثائق المتأثرة محدّثة

> `doc-coverage` يرفض تغيير كود بلا تحديث السجل واللوحة معاً في النطاق نفسه.
