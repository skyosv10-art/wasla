# `M0-24` — خطُّ CI الحيُّ داخلَ مرشِّحِ التغييراتِ ذاتِ المعنى (إغلاقُ `RISK-0021`)

**ما كانَ:** المرشِّحُ يذكرُ `.gitlab-ci.yml` — إرثَ الهجرةِ — **ولا يذكرُ `.github/` قطُّ**، والخطُّ الحيُّ منذ 2026-08-25 هو GitHub Actions. **فالملفُّ الذي يُحدِّد كيف يُقاس كلُّ شيءٍ آخرَ كانَ الوحيدَ الذي يمرُّ بلا حجزٍ وبلا توثيقٍ** (مسبرٌ في مستودعٍ منسوخٍ: المدقِّقانِ `rc=0`).

**ما صارَ:** `\.github/` في `CODE_OR_CONFIG_PATHS` بالمصدرِ الواحدِ.

## الدليلُ — حالتانِ لا واحدةٌ

| الحالةُ | ما تُثبِتُه |
| --- | --- |
| «تعديلُ `.github/workflows` بلا حجزٍ يُرفَض» | فرعٌ حقيقيٌّ يُلحِقُ سطراً بـ`ci.yml` ⇒ **كلا المدقِّقَينِ يرفضُ**. |
| «حذفُ `.github` من المرشّح يُكشَف» (طفرةٌ) | تُسقِطُ البادئةَ من المصدرِ الواحدِ فتَنقلِبُ الحالةُ الأولى إلى **مرورٍ**. **ولولاها لَجازَ أن تخضرَّ الأولى لسببٍ لا صلةَ له بالمرشِّح.** |

**الحزمةُ كاملةً: 165 ناجحاً · 0 فاشلاً** — [`local-measurements/test-governance-after.raw.txt`](local-measurements/test-governance-after.raw.txt).

## عيبٌ ثانٍ كشفَه التنفيذُ

`parity_check` كانت تبني مسارَ المسبرِ **قبلَ نزعِ الهروبِ** لبادئاتِ المجلَّداتِ. **ولم يظهرِ العيبُ قطُّ لأنّه لم تكنْ في المرشِّحِ بادئةُ مجلَّدٍ مهروبةٌ**، فلمّا أُضيفت `\.github/` أعلنت الحزمةُ «اختلافاً» على مسارٍ لا وجودَ له. صُحِّحَ بنزعِ الهروبِ قبلَ التفريعِ — **ولم يُخفَّفِ الحكمُ ولم تُستثنَ البادئةُ**.

## وما لا يُدَّعى

- **لم يُجرَدْ تاريخُ المستودعِ** بحثاً عن تعديلاتِ `.github/` التي كانت ستُرفَض لو وُجِدَ الحارسُ. الدعوى: **البابُ محروسٌ من الآنَ** — لا شيءَ عمّا مرَّ منه.
- الحارسُ يُلزِمُ بحجزٍ وتوثيقٍ، **ولا يقرأُ مضمونَ التعديلِ**: إسقاطُ وظيفةٍ يبقى مرئيّاً في الفرقِ لا مرفوضاً آليّاً.

## ملحوظةٌ على الامتدادِ

كُتِبَ هذا الخامُّ أوّلاً بامتدادِ `.log`، **و`.gitignore` يستبعدُ `*.log`** — فكانَ سيُحيلُ إليه ثلاثةُ مواضعَ في `main` **إلى ملفٍّ لا وجودَ له**. رُصِدَ قبلَ الدمجِ بمقارنةِ فَرقِ الدفعِ بالملفّاتِ المكتوبةِ، وصُحِّحَ بالامتدادِ `.raw.txt` الذي يستعملُه سائرُ الأدلّةِ المحلّيّةِ. **ولم يُستثنَ المسارُ من `.gitignore`**: القاعدةُ صحيحةٌ والخطأُ كانَ في التسميةِ.
