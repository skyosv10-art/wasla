# `M0-25` — حارسُ منعِ الدمجِ: الفحصُ الثامنُ لم يعُدْ «جزئيّاً أبداً»

**ما كانَ:** فحصُ الحوكمةِ الثامنُ («CI مانعٌ») **يُحتسَبُ جزئيّاً دائماً** ويُعلِنُ صراحةً أنّه **لا يسألُ عن رفضِ الدمجِ عندَ الإخفاقِ** — وكانَ ذلك **صدقاً** يومَ كُتِبَ: الإعدادُ `only_allow_merge_if_pipeline_succeeds = false` مقيسٌ على GitLab في 2026-08-27.

**وما تغيّرَ تحتَه:** الخطُّ الحيُّ صارَ GitHub Actions، والحمايةُ **27 سياقاً مطلوباً**، **والمنعُ مُبرهَنٌ بمحاولتَي دمجٍ رُدَّتا بـ`405`** (`M0-22E`). **فبقاءُ الفحصِ «جزئيّاً أبداً» صارَ بخساً للحقيقةِ بعدَ أن كانَ صدقاً فيها.**

## وما الذي يقيسُه الحارسُ حقّاً

**لا يقيسُ «أنّ الحمايةَ مفعَّلةٌ»** — فذاك إعدادٌ خارجَ المستودعِ لا يملكُ سكربتٌ محلّيٌّ إثباتَه. يقيسُ **ما يملكُ المستودعُ إثباتَه**:

| البابُ | ما يُرفَض به |
| --- | --- |
| 1) صيغةُ اللقطةِ | لقطةٌ بلا حقولٍ أو بصيغةٍ مجهولةٍ |
| **2) المطابقةُ (الحيُّ)** | **وظيفةٌ في `ci.yml` بلا سياقٍ مطلوبٍ يقابلُها — أو العكسُ** |
| 3) `strict` · `enforce_admins` | فرعٌ قديمٌ يُدمَج · مالكٌ يتجاوزُ الحارسَ |
| 4) برهانُ الرفضِ | لقطةٌ بلا محاولةِ دمجٍ رُدَّت بـ`405`، أو بمرجعٍ خامٍّ ميتٍ |

**والبابُ الثاني هو الحيُّ:** إضافةُ وظيفةٍ إلى الخطِّ بلا تسجيلِها في الحمايةِ **هي الطريقةُ الوحيدةُ التي يُفقَدُ بها المنعُ صامتاً بعدَ إثباتِه** — والحارسُ يُخفِقُ عليها.

## الدليلُ: سبعُ حالاتٍ، كلٌّ تُسقِطُ بابَها وحدَها

`test-governance.sh` ⇒ **172 ناجحاً · 0 فاشلاً** ([خامٌّ](local-measurements/test-governance-after.raw.txt)). ومنها:
«وظيفةٌ في الخطِّ بلا سياقٍ مطلوبٍ تُرفَض» · «`enforce_admins` معطَّلاً يُرفَض» · «لقطةٌ بلا برهانِ رفضٍ `405` تُرفَض» · «مرجعُ برهانِ الرفضِ الميتُ يُرفَض» · «حمايةٌ حيّةٌ انحرفت عن اللقطةِ تُرفَض».
**وحالةٌ تُثبِتُ أنّ الحارسَ لا يُجمِّلُ نفسَه:** لقطةٌ صحيحةٌ تماماً ⇒ **رمزُ 2 (جزئيٌّ مُعلَنٌ) لا 0**.

**وأوّلُ دليلٍ أنّ حراسَ المستودعِ يعملونَ جاءَ قبلَ الاختباراتِ:** `validate-ci-mandatory.sh` **رفضَ دفعَ هذا الحارسِ نفسِه** لأنّه كانَ «حارساً يتيماً» لا يُوصَلُ إليه من `verify.sh` — فوُصِلَ ثمّ مرَّ.

## وما لا يُدَّعى

- **اللقطةُ مؤرَّخةٌ لا حيّةٌ.** الفحصُ الثامنُ يبقى **جزئيّاً مُعلَناً (رمزُ 2)**، ولا يصيرُ `0` إلّا بتصديرِ `WASLA_PROTECTION_JSON` إلى ردٍّ حيٍّ يُطابقُ اللقطةَ. **ولم تُوصَلْ سلسلةُ CI بالواجهةِ**: توكنُ الخطِّ الافتراضيُّ لا يقرأُ إعداداتِ الحمايةِ.
- **مَن ملكَ صلاحيةَ الإدارةِ يستطيعُ تغييرَ الحمايةِ** — وهذا الحارسُ **يكشفُ الانحرافَ عندَ إعادةِ القياسِ لا يمنعُه**.
- الحارسُ **لا يقرأُ مضمونَ الوظائفِ**: وظيفةٌ مسجَّلةٌ في الحمايةِ لكنّها فارغةٌ تمرُّ — وذاك ما يحرسُه `validate-ci-mandatory.sh` و`RISK-0022`.
