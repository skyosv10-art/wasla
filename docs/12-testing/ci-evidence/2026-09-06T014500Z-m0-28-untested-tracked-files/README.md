## الخلاصةُ

## وما لا يُدَّعى

**لا يُدَّعى أنّ التغطيةَ كافيةٌ** — المقيسُ أنّ كلَّ مكتوبٍ يركض، لا أنّ المكتوبَ يكفي. **ولا يُدَّعى أنّ العدَّادَينِ صارا مقارَنَينِ**؛ هما نطاقانِ مختلفانِ، وإصلاحُ ذلك **قرارُ مالكِ `M0-08`**. **ولم يُفتَحْ خطرٌ لأنّ المقيسَ لم يكن عيباً** — وفتحُ خطرٍ بلا عيبٍ إفسادٌ للسجلِّ كإخفاءِ عيبٍ. **والقراءةُ لقطةُ جريةٍ واحدةٍ لا ضمانٌ دائمٌ:** لا حارسَ يمنعُ ملفّاً جديداً يُستثنى بلا وظيفةٍ.
