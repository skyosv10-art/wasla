## 1. الاكتشافُ المقيسُ قبلَ الشيفرةِ

آخرُ فجوةٍ مُعلَنةٍ في نصِّ RISK-0027 بعدَ CLM-0654 وCLM-0667: «المقابسُ الخامُّ (`node:net` · `node:tls`) خارجَ البصرِ». القياسُ على الشجرةِ الحيّةِ (main `7716cc54`):

```bash
grep -rlE "from ['\"](node:)?(net|tls|dgram)['\"]|require\(['\"](node:)?(net|tls|dgram)['\"]\)" \
  services bots packages --include='*.ts' --exclude-dir=node_modules --exclude-dir=dist \
  --exclude-dir=__tests__ --exclude='*.test.ts'
```

**النتيجةُ: 10 ملفّاتٍ في `packages/*-e2e` (harness/stub) — كلُّها من نوعِ `import type { AddressInfo } from "node:net"` وحدَها.** لا استخداماً تشغيليّاً للمقابسِ الخامّ في المستودعِ. الفجوةُ عمىً محتمَلٌ (البابُ 7 لا يرى من يخاطبُ الحدودَ بمقبسٍ خامٍ بلا هويّةِ خدمةٍ أصلاً) لكنها غيرُ مُستغلَّةٍ — فالعلاجُ حارسٌ لا إصلاحُ سلوكٍ.

## 2. التغييرُ — البابُ 7-د في `validate-service-auth-coverage.sh`

- `SOCKET_PATTERN` يُحصي مراجعَ `net`/`tls`/`dgram` (ببادئةِ `node:` وبلا بادئةٍ): استيراداً ثابتاً (`from`) أو `require(...)` أو `import(...)` ديناميكياً.
- **استثناءُ الاستيرادِ النوعيِّ:** الملفُّ يُحصى فقط إن وُجدَ فيهِ مرجعُ مقبسٍ **ليسَ** `import type` — فالنوعيُّ يُمحى عندَ الترجمةِ فلا مقبسَ تشغيليّاً (وهي حالةُ الشجرةِ الحيّةِ نفسُها؛ لو حُصيَ لصارَ الاستثناءُ قاعدةً تُخفي الفرقَ بينَ النوعيِّ والتشغيليِّ).
- التنفيذُ بلا أنبوبٍ يُغذّي `grep -q` (قاعدةُ RISK-0037): أسطرُ المراجعِ تُكتَبُ في ملفٍّ مؤقّتٍ ثمّ `grep -qv 'import type'` سؤالاً مباشراً.
- أُعيدَت صياغةُ رسالةِ النجاحِ: «لا مُناديَ خامٍ ولا جالبَ محقونٍ ولا مقبساً خامّاً خارجَ البصرِ: 42 ملفّاً (19 عميلاً + 23 استثناءً مُعلَناً · مقابسٌ تشغيليّةٌ: 0)».

## 4. الحدودُ المُعلَنةُ (لا تُدَّعى)

- grep لا AST: البناءُ الديناميكيُّ لاسمِ الوحدةِ (`import("node:" + "net")`) خارجَ البصرِ، والقفزاتُ عبرَ الملفّاتِ كما كانت.
- استثناءُ `import type` يعتمدُ على أنّ السطرَ النوعيَّ يحملُ `import type` في سطرِ المرجعِ نفسِهِ — استيرادٌ نوعيٌّ متعدّدُ الأسطرِ (`} from "node:net"` في سطرٍ بلا `import type`) سيُحصى خطأً حتى يُعلَنَ استثناءً؛ الخطأُ نحوَ البصرِ لا العمى.
- `mktemp` مؤقّتٌ يُنظَّفُ فورَ انتهاءِ الجردِ.
