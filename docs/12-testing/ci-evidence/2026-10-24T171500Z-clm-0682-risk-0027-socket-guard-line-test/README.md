# CLM-0682 — G-S9.19 / RISK-0027: الاستثناءُ النوعيُّ في بابِ 7-د تعليمةً لا سطراً

- **Claim:** `CLM-0682` · **Branch:** `fix/clm-0682-risk-0027-socket-guard-line-test` · **التاريخ:** 2026-10-24
- **Kind:** إصلاحُ حارسٍ — لا تغييرَ في شيفرةِ الإنتاجِ. لا نشرَ ولا كتابةَ إنتاجٍ ولا اتصالٌ خارجيٌّ.
- **ملاحظةُ حدودٍ:** RISK-0027 يبقى `open` (قرارُ المالكِ).

## 1. العيبُ الذي كشفتْهُ مراجعةٌ مستقلةٌ (بعدَ دمجِ CLM-0681)

استثناءُ الاستيرادِ النوعيِّ في بابِ 7-د كانَ **سطرَ فرعيَّ مطابقةٍ**: `grep -qv 'import type'` يستثني السطرَ لمجردِ ورودِ العبارةِ فيهِ لا لأنّهُ تعليمةَ استيرادٍ نوعيّاً فعلًا. حالتانِ مقيسَتانِ تُثبتانِ العيبَ (الشجرةُ الاصطناعيةُ قبلَ الإصلاحِ):

```ts
// الحالةُ 1 — سطرٌ تشغيليٌّ يحملُ التعليقَ، كانَ يُستثنى خطأً:
import { connect } from "node:net"; // import type
export const dial = () => connect(3000, "wasla-marketplace");

// الحالةُ 2 — require تشغيليٌّ بعدَ استيرادٍ نوعيٍّ في السطرِ نفسِهِ، كانَ يُستثنى خطأً:
import type { AddressInfo } from "node:net"; const tls = require("tls");
export const dial = (a: AddressInfo) => tls.connect(a.port, "wasla-marketplace");
```

## 2. الإصلاحُ

في `validate-service-auth-coverage.sh` (بابُ 7-د): يُقصُّ من رأسِ كلِّ سطرِ مرجعٍ تعليمةُ استيرادٍ نوعيٍّ كاملةً (`import type …;` — أو ذيلُ استيرادٍ نوعيٍّ متعدّدِ الأسطرِ `} from "net";`) ثمّ يُفحَصُ **الباقي** ضدَّ `SOCKET_PATTERN`:

```bash
_sock_rest="$(printf '%s' "$_sock_line" | sed -E 's/^[[:space:]]*(import[[:space:]]+type\b[^;]*;?|}[[:space:]]*from[[:space:]]*["'"'"'][^"'"'"']+["'"'"'];?)[[:space:]]*//')"
if grep -qE "$SOCKET_PATTERN" <<< "$_sock_rest"; then printf '%s\n' "$f"; break; fi
```

- الحالةُ 1: لا قصَّ (السطرُ لا يبدأُ بتعليمةِ استيرادٍ نوعيٍّ) ← يُحصى. الحالةُ 2: يُقصُّ الاستيرادُ النوعيُّ ويبقى `const tls = require("tls");` ← يُحصى.
- الاستيرادُ النوعيُّ متعدّدُ الأسطرِ (`} from "node:net";` في سطرٍ بلا تعليمةٍ) يُقصُّ ذيلُهُ فلا يُحصى.
- بلا أنبوبٍ يُغذّي `grep -q` (RISK-0037): `grep -qE … <<< "$rest"` سؤالٌ مباشرٌ بنصٍّ جاهزٍ.
