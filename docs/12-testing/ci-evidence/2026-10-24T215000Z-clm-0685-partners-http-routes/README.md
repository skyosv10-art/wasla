# CLM-0685 — M0-53: اختباراتُ مستوىِ HTTP لمساراتِ الشركاءِ الثلاثةِ غيرِ المُختبَرةِ

**التاريخ:** 2026-10-24 · **الفرع:** `fix/clm-0685-partners-http-route-tests` · **الأساس:** main `3e304265` (ما بعدَ دمجِ #829)

## الهدف

سدُّ فجوةِ قياسٍ مُعلَنةٍ في `PRODUCT_STATUS_2026-10-19.md` §3.4: ثلاثةُ
مساراتِ شركاءَ قائمةٌ في `services/partners` بلا أيِّ اختبارٍ:

- `DELETE /partners/credentials/:id` (إبطالُ اعتمادِ API)
- `POST /partners/lifecycle/suspend` (تعليقُ مستأجرٍ)
- `POST /partners/lifecycle/reinstate` (إعادةُ تنشيطِ معلَّقٍ)

قاعدةُ الخارطةِ الحاكمةِ (`0.2`): التنفيذَ يُثبتُهُ الدليلُ المحالُ إليهِ
حصرًا — وجودُ المسارِ في الشيفرةِ ليسَ دليلًا. المساراتُ الثلاثةُ كانتْ
موجودةً ومُصنَّفةً (validate-service-auth-coverage يفحصُ التصنيفَ) لكن بلا
سلوكٍ مُثبَتٍ ولا فرضِ هويّةٍ مُقاسٍ عندَها.

## الملفُّ

`services/partners/src/__tests__/http-routes.unit.test.ts` — 15 حالةً
بمخازنَ وهميّةٍ صادقةِ الوعدِ (لا قاعدةَ ولا شبكةَ)، على طبقتينِ:

### الطبقةُ الأولى: السلوكُ (9 حالاتٍ)

| الحالةُ | النتيجةُ |
| --- | --- |
| مالكٌ يُبطلُ اعتمادًا | 204 · الاعتمادُ مُعلَّمٌ · `credential.revoked` في التدقيقِ |
| بلا `x-wasla-principal` | 401 `AUTHN_UNAUTHENTICATED` قبلَ أيِّ مخزنٍ |
| غيرُ عضوٍ | 403 `TENANT_ACCESS_DENIED` ولا إبطالَ |
| دورُ staff (دونَ مديرٍ) | 403 `TENANT_ROLE_DENIED` — حارسُ الدورِ عندَ المسارِ |
| اعتمادٌ غيرُ موجودٍ | 500 ظاهرٌ لا نجاحٌ صامتٌ |
| تعليقُ نشِطٍ | 200 `suspended` · الانتقالُ بالسببِ · `lifecycle.suspended` |
| تعليقُ مُنهى (offboarded) | رفضُ الانتقالِ (لا تنفيذَ ولا تدقيقَ) |
| تنشيطُ معلَّقٍ | 200 `active` · `lifecycle.reinstated` |
| تنشيطُ نشِطٍ (انتقالٌ غيرُ مشروعٍ) | رفضٌ لا تنفيذَ |
| مسارا الدورةِ بلا فاعلٍ | 401 من كليهما |

### الطبقةُ الثانية: هويّةُ الخدمةِ بتوقيعٍ حقيقيٍّ (6 حالاتٍ)

- بلا رمزِ خدمةٍ → 401 من وسيطِ الحدِّ قبلَ منطقِ المسارِ.
- رمزٌ صالحٌ بصلاحيّةٍ ناقصةٍ → 403 `AUTHZ_FORBIDDEN`.
- الصلاحيّةُ المعلَنةُ لكلِّ مسارٍ → النجاحُ (204/200).
- التوقيعُ يُنشئُهُ `serviceAuthHeaders` بمفتاحٍ نشطٍ في
  `ServiceAuthKeyRegistry` حقيقيٍّ، والتحققُ يُؤدّيهِ وسيطُ الحدِّ — لا ختمَ
  ولا تجاوزَ.
