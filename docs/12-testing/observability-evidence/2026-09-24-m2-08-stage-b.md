### OTLP tracing

`OTEL_EXPORTER_OTLP_ENDPOINT` set to `https://wasla-otel-collector.onrender.com/v1/traces` on all 14 HTTP services. Tracing is opt-in — services start with `startTracing()` which is a no-op when `OTEL_EXPORTER_OTLP_ENDPOINT` is unset, and sends OTLP traces when set.

### SLI alert rules

Four SLI-based alert rules defined in `infra/observability/alert-rules.yml`:

1. `ServiceDown` — any target `up == 0` for 1 min
2. `HighErrorRate` — `rate(http_requests_total{status=~"5.."}[5m]) / rate(http_requests_total[5m]) > 0.05` for 5 min
3. `HighLatencyP95` — histogram_quantile(0.95, ...) > 0.5 for 5 min
4. `LowAvailability` — `1 - (rate(http_requests_total{status=~"5.."}[5m]) / rate(http_requests_total[5m])) < 0.99` for 5 min
