# المرجع — الوثيقة الأم الأصلية

هذا المجلد يحتوي على الوثيقة الأم الأصلية `WASLA_MASTER_EXECUTION_DOCUMENT.md` (v1.0 Baseline) التي بُني منها هيكل هذا المستودع.

## العلاقة بالوثائق النمطية

- **الحقيقة العاملة** تعيش في الوثائق النمطية تحت `docs/00-rules` حتى `docs/17-launch` وفي سجلّ القرارات `docs/15-decisions`.
- هذه الوثيقة الأم **مرجع أرشيفي** يُحافظ على السياق الكامل والترتيب التاريخي للقرارات.
- عند تعارض محتوى، تعمل نسخة الوثائق النمطية المحدّثة، ويُفضّل نقل النقاط إلى ADR عند وصول العمل إليها.

## قاعدة التعديل

لا يُحذف أو يُعدّل محتوى هذه الوثيقة مباشرةً. أي تغيير في القرار يجب أن يمرّ عبر:

```
Old Decision → ADR → New Decision → Impact Analysis → Docs Update → Migration Plan
```
