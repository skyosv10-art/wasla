# عقودُ خدمةِ الوفاءِ (`services/delivery`)

**الطورُ 13 · العنصرُ `M5-13` · القرارُ الحاكمُ [ADR-026](../../../docs/15-decisions/ADR-026-store-order-delivery-workflow.md).**

| الملفُّ | ما يُلزِمُ به |
|---|---|
| [`schema.sql`](schema.sql) | **عقدُ** المخطَّطِ: القيودُ تُنفِّذُ أحكامَ المجالِ في القاعدةِ نفسِها لا فوقَها. **ليس مهاجراً** — المهاجرُ العكسيُّ (ADR-024) مراجعةٌ لاحقةٌ. |
| [`events.json`](events.json) | حمولاتُ الأحداثِ. لا مالَ ولا نصَّ حرٍّ ولا بياناً شخصيّاً، ولا حدثَ نيّةٍ. |
| [`errors.md`](errors.md) | رموزُ الرفضِ المغلقةُ. |

**ما لم يُبنَ بعدُ ولا يُدَّعى:** محوّلاتُ PostgreSQL · طبقةُ HTTP ومسبارُ الجاهزيّةِ ·
مستهلكُ أحداثِ السوقِ والإسنادِ · محرّكُ `outbox` · بوّابةُ الخروجِ (`inventory/payment E2E`).
انظر [ADR-026 §4](../../../docs/15-decisions/ADR-026-store-order-delivery-workflow.md).
