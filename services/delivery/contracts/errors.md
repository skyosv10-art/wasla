# أخطاءُ خدمةِ الوفاءِ — رموزٌ مغلقةٌ تُعَدُّ ولا تُقرأُ

**المصدرُ الحاكمُ:** [ADR-026](../../../docs/15-decisions/ADR-026-store-order-delivery-workflow.md).
كلُّ رمزٍ هنا **حكمٌ من أحكامِ المجالِ** تُصدرُه دالّةٌ نقيّةٌ لا استثناءٌ برمجيٌّ،
ولذلك يُعَدُّ ويُرسَمُ بيانيّاً: «كم شحنةً رُفضَ انتقالُها لأنّ الفاعلَ غيرُ مخوَّلٍ؟»
سؤالٌ يُجابُ بالعدِّ.

| الرمزُ | متى | HTTP المقترحُ (طبقةُ HTTP لم تُبنَ بعدُ) |
|---|---|---|
| `DELIVERY_SEQUENCE_CONFLICT` | التسلسلُ المُتوقَّعُ لا يطابقُ المُخزَّنَ — كتابةٌ متزامنةٌ | `409` |
| `DELIVERY_TERMINAL_STATE` | محاولةُ مغادرةِ حالةٍ منتهيةٍ | `409` |
| `DELIVERY_TRANSITION_NOT_ALLOWED` | الانتقالُ ليس في الجدولِ — **وما ليس فيه ممنوعٌ** | `422` |
| `DELIVERY_ACTOR_NOT_PERMITTED` | الانتقالُ مسموحٌ لكنّ الفاعلَ ليس من أهلِه | `403` |
| `DELIVERY_ACTOR_REF_INVALID` | فاعلٌ بشريٌّ بلا مرجعٍ، أو `system` بمرجعِ شخصٍ | `422` |
| `DELIVERY_DRIVER_REQUIRED` | حالةٌ تحملُ سائقاً بلا مرجعِ سائقٍ | `422` |
| `DELIVERY_DRIVER_NOT_EXPECTED` | مرجعُ سائقٍ في انتقالٍ لا يعنيه | `422` |
| `DELIVERY_REASON_REQUIRED` | نهايةٌ غيرُ ناجحةٍ بلا سببٍ مُصنَّفٍ | `422` |
| `DELIVERY_REASON_NOT_EXPECTED` | سببُ إخفاقٍ في انتقالٍ ناجحٍ | `422` |

**ما لا يُوجَدُ هنا عمداً:** لا رمزَ دفعٍ ولا رمزَ رصيدٍ. الدفعُ حدُّ `M5-17`،
وحجزُ المخزونِ قرارٌ مؤجَّلٌ (ADR-026 §4) — ورمزُ خطأٍ لحدٍّ لم يُبنَ **ادّعاءٌ**.
