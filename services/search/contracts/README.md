# Search Service — Contracts (Phase 12)

> **Scope:** عقدُ خدمةِ البحثِ في السوقِ (Contract-First، ADR-004). مصدرُ الحقيقةِ للواجهةِ والأحداثِ والأخطاءِ والمخطَّطِ.
>
> **المبدأ (ADR-025):** الفهرسُ نموذجُ قراءةٍ مشتقٌّ من أحداثِ السوقِ، لا قراءةٌ مباشرةٌ من جداولِ السوقِ. الظهورُ مُشتقٌّ من الحالةِ المُستهلكةِ (ADR-016 القرارُ 3). البحثُ ثنائيُّ اللغةِ والترتيبُ مفسَّرٌ.
>
> **Related:** [ADR-025](../../../docs/15-decisions/ADR-025-marketplace-search-read-model.md) · [ADR-016](../../../docs/15-decisions/ADR-016-marketplace-store-ownership-catalog-and-moderation-boundary.md)

## النطاقُ في PR الأول (التأسيس)

هذا PR أولُ تأسيسيٌّ (review 1/N) لـ M5-12. ما يُغطّيه:

- عقدُ الفهرسِ والواجهةِ والأحداثِ والأخطاءِ.
- نواةُ النطاقِ: تطبيعُ الاستعلامِ (عربي/إنجليز)، قواعدُ الترتيبِ المفسَّرة، قواعدُ الظهورِ.
- اختباراتُ وحدةٍ/عقودٍ للحالاتِ الأساسيّةِ.

ما **يُؤجَّلُ** لمراجعاتٍ لاحقةٍ (مُسجَّلٌ في ADR-025 §4 وTASK_LOG):

- المستهلكُ الكاملُ (relay) لأحداثِ outbox السوقِ.
- بوّابةُ relevance/load (exit gate مستقلّ).
- اختباراتٌ تكامليّةٌ على PostgreSQL حقيقيّ + وظائفُ CI المقابلة.
- طبقةُ HTTP الكاملةُ (Fastify app) + التركيبُ (composition root).
